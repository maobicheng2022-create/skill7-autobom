# 01 · 环境要求

## 1. 系统

- Windows 10 / 11，**64 位**
- 有桌面会话（SolidWorks 是桌面程序，脚本通过 COM 连它；纯 SSH/服务会话连不上）
- 磁盘：仓库 + AutoBOM 约 60 MB；截图缓存随零件数增长（几千个零件约 100 MB 起）

## 2. SolidWorks

| 项 | 要求 |
|---|---|
| 版本 | 2019 及以上；实测 **2022（30.x）/ 2025（33.x）** |
| 语言 | 中/英文界面均可（脚本走 API，不依赖界面文字，弹窗关键字除外） |
| 宏 | 允许运行 VBA 宏（默认允许；若被安全策略禁用，步骤 10 型材宏会失败） |
| 许可 | 必须能正常打开**装配体**并保存（不是只看图） |

自查安装位置（多版本并存时用得上）：

```powershell
Get-ItemProperty "HKLM:\SOFTWARE\SolidWorks\SOLIDWORKS 2025\Setup" | Select-Object 'SolidWorks Folder'
```

如果机器上同时装了 2022 和 2025，`shared/skill7_paths.py` 会按注册表取**版本号最高**的那个；
想固定用某个版本，在 `config\config.json` 里写死：

```json
{ "solidworks_exe": "E:\\Program Files\\SOLIDWORKS Corp\\SOLIDWORKS\\sldworks.exe" }
```

## 3. Python

- **64 位**（重要：32 位 Python 连不上 64 位 SolidWorks 的 COM，报 "无效类字符串" / 80040154）
- 3.10+（实测 3.14.3）

```powershell
python -V                 # 看到 Python 3.x.y，且是 64 位
python -c "import struct,sys;print(struct.calcsize('P')*8, sys.version)"
```

安装依赖：

```powershell
python -m pip install --upgrade pip
python -m pip install pywin32 openpyxl Pillow ezdxf
```

| 包 | 用途 |
|---|---|
| `pywin32` | SolidWorks / AutoCAD COM、弹窗处理 |
| `openpyxl` | 读写 xlsx（BOM 表、截图嵌入） |
| `Pillow` | 截图缩放/嵌入 |
| `ezdxf` | 合并 DXF、统计槽/孔图层 |

> 建议用官方 python.org 安装包，安装时勾 "Add python.exe to PATH"。
> 用 Microsoft Store 版 Python 也行，但 COM 组件注册（pywin32 post-install）偶发异常，出问题换官方版。

## 4. AutoBOM（第三方插件）

- 仓库自带便携版（`autobom\portable`），`tools\install.ps1` 会装到 `C:\AutoBOM` 并注册。
- 需要 **.NET Framework 4.8**（Win10 1903+ / Win11 自带，无需另装）。
- 注册需要**管理员权限**（写 HKLM / HKCR）。
- 授权：AutoBOM 是第三方商业插件，本仓库只做便携化打包，**商用请自行向原厂取得授权**（见 [NOTICE.md](../NOTICE.md)）。

## 5. SolidWorks 宏

- 仓库 `macros\` 下 14 个 `.swp`，`install.ps1` 默认装到仓库 `macros\`，也可 `-MacroDir` 指到共享盘（如 `D:\macros`）。
- 关键两个：`零件分类.swp`、`型材零件名称数量合成另存文件夹.swp`。
- 宏里若有写死的输出路径，需要按你的环境改（本仓库的宏按"当前装配体/当前目录"工作，不含写死路径）。

## 6. AutoCAD（可选）

只有需要把 `.dwg` 转 `.dxf` 时才用（`skills\6-合并DXF\scripts\dwg2dxf.py`）：

- AutoCAD 2018+，能正常启动、COM 可连接
- 自动探测顺序：`config.acad_exe` → 注册表 `HKLM\SOFTWARE\Autodesk\AutoCAD\*\*\AcadLocation` → PATH
- 如果图纸本来就是 DXF，**完全不需要 AutoCAD**

## 7. Office / WPS（可选）

只在你自己打开产物时需要。产物是标准 `.xlsx` / `.csv` / `.dxf`，WPS、Excel、LibreOffice 都能开。

## 8. 权限要点

- `tools\install.ps1` 注册插件时需管理员；只装文件可用 `-SkipRegister`。
- SolidWorks 与脚本必须**同一个 Windows 用户**启动（COM 是会话级的）。
- 杀软可能拦 `.swp` 宏或 AutoBOM 的截图临时文件，遇到莫名失败先看杀软日志。

## 9. 最小可行清单

- [ ] Win10/11 64 位
- [ ] SolidWorks 能开总装
- [ ] 64 位 Python 3.10+，四个依赖包装好
- [ ] `C:\AutoBOM` 有文件，SW 插件列表里能看到 AutoBOM
- [ ] `C:\micDatas\pluginSettings\BOM\setting.json` 有 8 套模板
- [ ] `macros\` 有 14 个 `.swp`
- [ ] `python -X utf8 tools\verify_env.py` 全 OK

全过就可以跑 [04-运行skill7](04-运行skill7.md)。
