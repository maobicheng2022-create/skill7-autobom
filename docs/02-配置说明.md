# 02 · 配置说明

所有"机器相关的绝对路径"都由 `shared/skill7_paths.py` 统一解析，脚本里不再写死。

## 1. 解析优先级（从高到低）

1. **环境变量** `SKILL7_<键名大写>`，如 `SKILL7_AUTOBOM_DIR=D:\AutoBOM`
2. **配置文件**，按顺序找第一个存在的：
   - `SKILL7_CONFIG` 指向的文件
   - `<仓库>\config\config.json`
   - `%USERPROFILE%\.skill7\config.json`
3. **自动探测**（注册表 / 常见安装路径 / 仓库自带模板）
4. **内置默认值**

## 2. 配置键

| 键 | 环境变量 | 默认 | 说明 |
|---|---|---|---|
| `solidworks_exe` | `SKILL7_SOLIDWORKS_EXE` | 自动探测 | SolidWorks 主程序；多版本并存时建议写死 |
| `autobom_dir` | `SKILL7_AUTOBOM_DIR` | `C:\AutoBOM` | AutoBOM 安装目录（exe/dll/Plugin 所在） |
| `micdatas_dir` | `SKILL7_MICDATAS_DIR` | `C:\micDatas` | BOM 模板目录，下面应是 `pluginSettings\BOM\setting.json` |
| `shot_cache_dir` | `SKILL7_SHOT_CACHE` | 自动探测 | 截图/属性缓存库；多份时选 `shot_index.db` 最新的 |
| `macro_dir` | `SKILL7_MACRO_DIR` | 仓库 `macros\` | SW 宏目录（`.swp`） |
| `acad_exe` | `SKILL7_ACAD_EXE` | 自动探测 | 仅 `.dwg→.dxf` 时用 |
| `pdm_library_markers` | `SKILL7_PDM_LIBRARY_MARKERS` | `[]` | PDM 只读库路径关键字（小写比较），命中后：桌面有同名可写副本→重定向；没有→跳过不处理 |

## 3. 最简配置（一台机器）

`config\config.json`：

```json
{
  "solidworks_exe": "",
  "autobom_dir": "C:\\AutoBOM",
  "micdatas_dir": "C:\\micDatas",
  "macro_dir": "C:\\AutoBOM\\macros",
  "shot_cache_dir": "",
  "acad_exe": "",
  "pdm_library_markers": []
}
```

留空 = 自动探测。`install.ps1` 会自动生成一份，通常不需要手改。

## 4. 常见场景

### 4.1 装在 D 盘

```json
{
  "autobom_dir": "D:\\AutoBOM",
  "micdatas_dir": "D:\\micDatas",
  "macro_dir": "D:\\AutoBOM\\macros"
}
```

同时部署时对应：

```powershell
.\tools\install.ps1 -AutoBomDir D:\AutoBOM -MicDatasDir D:\micDatas -MacroDir D:\AutoBOM\macros
```

### 4.2 宏放共享盘（多台电脑共用一套宏）

```json
{ "macro_dir": "\\\\nas\\sw-macros" }
```

### 4.3 用 PDM 库图纸

总装引用指向 PDM 只读库时，直接 `Save()` 会弹"另存为"阻塞流程。配置后自动处理：

```json
{ "pdm_library_markers": ["d:\\feedinghero", "\\\\pdm-server\\vault"] }
```

命中规则：零件路径包含任一关键字（小写）→ 视为 PDM 库件。

### 4.4 不写文件，只用环境变量（CI / 临时切换）

```powershell
$env:SKILL7_AUTOBOM_DIR = "D:\AutoBOM"
$env:SKILL7_MACRO_DIR   = "D:\macros"
python -X utf8 tools\verify_env.py
```

## 6. 配置改了不生效？

- 检查是不是有环境变量在覆盖（`Get-ChildItem Env:SKILL7_*`）
- 检查 `%USERPROFILE%\.skill7\config.json` 是否被优先命中（优先级高于仓库 config）
- 子进程会继承环境变量；父进程里设的变量对已经在跑的任务无效

## 7. 给二次开发者的约定

新增任何路径，不要写进脚本，统一加到 `shared/skill7_paths.py`：

```python
MY_NEW_PATH = _norm(_get("my_new_path", r"C:\default"))
```

脚本里：

```python
from skill7_paths import MY_NEW_PATH
```

这样 `config.json` 和 `SKILL7_MY_NEW_PATH` 自动生效，别人部署时不用改代码。
