# Skill 10 — 虚拟件外部化与 Pipe_ 标记

给图纸文件夹做 SW 综合处理前置：**①把总装里所有虚拟零部件外部化保存到图纸文件夹**（解决虚拟件导致的 BOM 聚合失败、$宽/$高 读不到、截图打不开）；**②给 Pipe_/ST_ 前缀的装配体和零件写 采购类别=外购件**。

**已嵌入 skill7 工作流首位**（sw_doc_process.py 步骤 A，跑 skill7 自动执行，无需单独调用）。

## 一条命令（独立使用）

```bat
python -X utf8 "skills\10-虚拟件外部化与Pipe标记\scripts\sw_virtual_extract_and_mark.py" --dir "<图纸文件夹>" [--asm "<总装路径>"]
```

- `--dir` 必填：图纸文件夹
- `--asm` 可选：显式指定总装（缺省自动找，已排除 ST_/Pipe_/~$ 前缀）
- `--no-guard`：复用外部弹窗守卫（skill7 内嵌时自动加，勿手动传）

## 做了什么

1. **外部化**：打开总装 → 解析轻化组件 → 找虚拟零部件（判据：路径空 / 含 `\VC~~\` 或 `\temp\swx` / 名字含 `^`，如 `DN15TK23^Pipe_2-xxx.SLDPRT`）→ **`IComponent2.SaveVirtualComponent(target)`** 保存到图纸文件夹（文件名取 `^` 后部分，补 `.SLDPRT` 扩展名；IComponent2 **没有 SaveAs 方法**，用 SaveAs 会 AttributeError）→ 保存总装（引用自动改外部）→ 关闭总装
2. **标记**：遍历文件夹，`Pipe_`/`ST_` 前缀（大小写不敏感，含 `_`/`＿` 全角）的 `.sldprt`/`.sldasm` → 写 `采购类别=外购件`（Add2 配置特定属性，不碰其他属性）→ Save → CloseDoc

## 产出校验

- 日志显示 `外部化 N 个虚拟件`、`完成: 成功 N, 失败 0`
- 图纸文件夹出现新文件（原虚拟件名，Pipe_ 前缀）
- 总装打开不再弹"该装配体包含未保存的虚拟零部件"

## 注意事项

- 依赖 `sw_popup_guard.py`（缺则拒绝启动）
- 外部化不可逆（虚拟→磁盘），**先备份再跑**
- 20260810/20260811 旧图均含 4 种虚拟件（`DN15TK23^Pipe_2/4/6-*`）→ 外部化后验证虚拟 0；**新图若有虚拟件，步骤A 自动处理；无虚拟件则只跑标记部分（外部化 0 属预期）**
