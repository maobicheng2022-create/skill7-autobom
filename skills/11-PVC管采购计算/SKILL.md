# 11-PVC管采购计算

从 SW 总装配体出发 + 套数 qty，统计所有 PVC 直管（步路/线路零件）需要什么规格、多长、多少根，再按 **6 米一根**折算需要买多少根管（一根 6m 管切完剩下的料不够再切就浪费，独立算不混切）。

> **唯一权威入口，命中就一条命令跑通。** 不要看代码、不要自己重写读取/下料逻辑。

## 怎么用（唯一入口）

```
python -X utf8 "skills\11-PVC管采购计算\scripts\sw_pvc_purchase.py" --dir "<图纸文件夹>" [--asm "<总装.sldasm>"] [--qty 套数] [-o 输出目录]
```

- `--dir`：图纸文件夹，必填（自动找总装：代号最短，排除 ~$ / ST_ / Pipe_）
- `--asm`：可选，显式指定总装配体 .sldasm 完整路径
- `--qty`：套数，必填语义（默认 1，建议显式指定）
- `-o`：输出目录（默认图纸文件夹）

## 识别与取值规则（自动，勿改）

- **管段识别**：组件名含 `线路` 或以 `Pipe_` 开头的零件（含装配体内的虚拟线路零件，不用另存外部）
- **规格**：优先取属性 `规格` → `直径` → `尺寸`，都没有用配置名（如 DN15）
- **长度**：优先 SW 自带 `长度` 属性（SW Routing 自动写入每个线路零件，单位 mm）；缺失时用零件包围盒最长边
- **数量**：每种 (规格, 长度) 的实例数 × qty 套

## 6m 管下料规则

- 每规格**独立**算（DN15 归 DN15，不同口径不混切）
- 一根 6m(6000mm) 管按 FFD 一维下料切各段长度，**剩余不够再切就浪费**，取最少根数
- 单段超 6m 的特殊段独占一根并在备注提示（需另购非标）

## 输出

1. 终端打印：每规格 单套段数 / 总长度 / 需 6m 管根数 / 余料
2. `PVC管采购表_YYYYMMDD_HHMMSS.xlsx`，两个 Sheet：
   - **采购汇总**：`规格 | 段数(单套) | 段数(xqty套) | 总长度(m) | 需6m管(根) | 余料(m) | 备注`
   - **切割明细**：`规格 | 每段长度(mm) | 数量(单套) | 数量(xqty套) | 小计(m) | 来源`

弯头/三通等管件**不在本表**，仍在总外购件采购表（总外购件模板的"型号规格"列已显示配置名）。

## 跑完怎么验证

- 抽查：某规格总长度 = Σ(每段长 × 数量×qty) / 1000
- 根数 ≥ ceil(总长/6000)，且每根 6m 的余料都 < 该规格最短一段
- 切割明细行数与装配体内线路零件一一对应（含虚拟件）

## 环境

- SW 运行中或可自动拉起（正常方式启动 + 弹窗守卫内嵌）；依赖 pywin32/openpyxl
- 无 AutoCAD / AutoBOM 依赖
