# 批量钣金展开导出 DWG/DXF（auto钣金展开插件）

> ⚡ **唯一权威入口，一条命令跑通。** 不要自行写展开脚本、不要研究 SW 展平 API——下面命令调用的 exe 已内置全部逻辑（命名/折弯线/卷圆抑制）。

## 怎么用（唯一入口）

前置：目标文件夹存在、SolidWorks 已打开运行。

```
C:\AutoBOM\AutoBaiJinZhanKai.exe 批量 <输入文件夹> [dxf|dwg]
```

- 第 1 参 `<输入文件夹>`：SW 钣金零件所在文件夹（必填）
- 第 2 参 格式：缺省 `dxf`，可填 `dwg`
- 批量导出该文件夹内全部钣金件的展开图，命名 `文件名-材质-板厚`，折弯线开启，卷圆件卷圆线不显示。
- **非钣金件**（无平板型式）会报"无法判断是否为钣金件"而跳过——这是正常行为，不是 bug。

## 跑完怎么验证

- 用展开产生的**产物/文件大小**判断成功，不要只看返回码（退出码有时不可靠）。
- 生成的 DXF/DWG 文件名符合 `文件名-材质-板厚`；卷圆件是展开平板（非立体），盖板折弯线保留。

## 维护参考（以下是人维护用，执行无需读）

### sheetMetalOptions 参数（实测定案，勿改）
- `sheetMetalOptions = "111"`（二进制 111 = 十进制 7）为正确值。传 `4`(空壳)、`7` 非法二进制会失败。

### 卷圆件展开 + 抑制卷圆折弯线（v3 修复）
- 只抑制**平板型式下有「基体折弯」/BaseBend UiBend 的真卷圆件**的「折弯-线」草图；普通折弯件(边线折弯如盖板)折弯线保留。勿回退 v1/v2（会破坏展开或误删盖板折弯线）。

### 关键源码
- 批量入口 `C:\AutoBOM\_src\AutoBaiJinZhanKai\TestSW2\BatchRun.cs`；主逻辑 `...\SWClass\SWAppClass.cs`；部署 exe `C:\AutoBOM\AutoBaiJinZhanKai.exe`；重编译 `cd C:\AutoBOM\_src\AutoBaiJinZhanKai && dotnet build -c Release`

### 坑 / 注意
- 过滤 `~$` 临时文件；OpenDoc6 返回元组取 [0]
- **SW 资源耗尽坑**：20 个复杂件反复批量导出会顶爆 SW 内存/句柄(7.5GB/11965) → OpenDoc6 全失败(2097152) → SW 崩溃。需重启 SW，勿反复高频测试。
