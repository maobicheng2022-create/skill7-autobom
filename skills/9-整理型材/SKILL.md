# 9-整理型材

把型材采购表按"同规格"归并，算出每种规格的管材总共要多长、按一根 6m 折算需要买多少条。

> ⚡ **唯一权威入口，命中就一条命令跑通。** 不要看代码、不要自己重写归并/折算逻辑——下面命令的脚本已全部内置。

## 怎么用（唯一入口）

```
python -X utf8 "skills\9-整理型材\scripts\xingcai_summary.py" "<型材采购.xlsx>"
```

- `<型材采购.xlsx>`：型材采购表，**必填**，第一个 sheet。
- 脚本自动：读表 → 按规格归并 → 算每组总长 → 折成 6m 管条数 → 打印终端汇总 + 生成汇总 xlsx。
- 可选参数：
  - `-o <输出.xlsx>`：指定汇总文件路径（默认在同目录生成 `整理型材_YYYYMMDD_HHMMSS.xlsx`）
  - `--optimize`：启用 1D 下料 FFD 拼管（多数与默认持平，默认已是最优下界，一般不用加）

## 输入表格要求（列名自动匹配，表头带不带 `$` 前缀都行）

- 至少要有这几列：`数量`、`宽`、`高`、`厚度`、`长`（列名如 `$总数量`/`$宽`/`$高`/`厚度`/`$长` 均可）
- 可选列：`名称`、`型材类型`（没有也能跑，类型归并会退化为按尺寸+厚度）、**`材质`**（2026-11-23 起：同规格不同材质分行统计）
- 长度单位 = **毫米(mm)**，一根管按 **6 米 = 6000mm** 折算。
- **材质口径**：只区分 `201` 与 `Q235镀锌管` 两类（由零件的「材料」解析值自动归类）；
  同一规格在两种材质下会输出**两行**，不会合并成一行。

## 同规格归并规则（脚本自动处理，您无需干预）

| 类型 | 判定"同规格"的标准 |
|---|---|
| 方管 / 长方管 | **长宽可调换视为同种**（40×20 与 20×40 并成一行），且**厚度相同**才归组，尺寸取小×大归一 |
| 圆管 | 按**直径** + 厚度归组 |
| 其他 | 尺寸(小×大) + 厚度归组 |

每组：
- **总长mm = Σ(长 × 数量)**
- **6m根数 = 向上取整(总长 / 6000)**
- **剩余mm = 6000 × 根数 − 总长**

## 输出

1. 终端打印汇总表 + 合计（`合计需采购 N 种规格，共 M 根 6m 管`）
2. 汇总 xlsx，列：`规格 | 类型 | 数量 | 总长mm | 6m根数 | 剩余mm | 实例`

## 跑完怎么验证（核数，不核代码）

- **抽查**：各规格 总长 = 该规格对应数据行 的 长×数量 之和
- 长宽调换的规格（如 40×20 与 20×40 厚度相同）**必须并成一行**，不能拆成两行
- 每规格 剩余 = 6000×根数 − 总长；根数永远 ≥ ceil(总长/6000)，且是整数

## 环境

- 仅需 `python` + `openpyxl`，**无 SolidWorks / AutoCAD 依赖**，纯表格计算。

## 维护参考（以下是人维护用，执行时别读代码来当用法）

- 规格 key 归一：圆管 `(直径, 厚)`；其他 `(类型, lo×hi, 厚)`，lo/hi = min/max(宽,高) 实现"长宽可调换"。
- `--optimize` 用 FFD（First-Fit Decreasing）一维下料；数学下界 = ceil(总长/6000)，故日常默认已最优，optimize 仅作排布参考。
- 列名匹配先去 `$` 前缀再比对中文列名。
